# Paystack activation video — how to record

Paystack needs a short video of a **party-goer buying a test ticket**.

## Option A — Easiest (recommended)

1. In File Explorer, go to `sec-night-life\`
2. **Double-click `OPEN-PAYSTACK-DEMO.bat`**
3. Microsoft Edge opens — sign in as party-goer
4. Press **Win + Alt + R** to start Windows screen recording
5. Buy a test ticket (card `4084084084084081`, CVV `408`, any future expiry)
6. Open **Profile → Tickets** and show the QR code
7. Press **Win + Alt + R** again to stop
8. Save the file as `launch-resources/paystack/payment-demo-ticket.mp4`

## Option B — Auto recorder

1. Double-click `sec-night-life\RECORD-PAYSTACK-DEMO.bat`
2. Edge opens automatically — sign in and complete checkout there
3. Press **Enter** in the black command window when done

> **Note:** Scripts started from Cursor’s AI chat often do **not** show a browser on your screen. Always use **double-click** from File Explorer.
